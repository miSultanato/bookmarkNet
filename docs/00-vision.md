# Visión

## El problema

Internet ya no tiene escasez de información. Tiene exceso.

Google responde: ¿Qué páginas existen? BookmarkNet responde: ¿Qué recursos considera útiles la comunidad?

## La propuesta

Una red P2P de bookmarks donde los usuarios organizan enlaces en grupos y colecciones, comparten conocimiento reutilizable, duplican colecciones existentes y descubren recursos valiosos a partir de patrones que emergen de la organización colectiva de la información.

## La observación fundacional

El problema ya no es encontrar información, sino encontrar información valiosa entre una cantidad creciente de contenido. En lugar de indexar toda la web como Google, la red almacena y comparte los enlaces que las personas consideran relevantes.

## El valor único

| Escenario | Google | BookmarkNet |
|---|---|---|
| Encontrar una URL concreta | Inmediato | Requiere curaduría previa |
| Descubrir qué recursos usa una comunidad | SEO contamina | Patrones de co-ocurrencia |
| Aprender una ruta (Docker → K8s) | No estructura rutas | Stacks emergentes |
| Conservar colecciones que evolucionan | No existe | Replicación + seguimiento |
| Compartir curaduría con propiedad | No existe | Criptográfico |

## Visión a largo plazo

Un Internet donde el valor no está en quién produce más contenido, sino en quién identifica, organiza y conecta el conocimiento existente.

BookmarkNet es Git para los enlaces.
